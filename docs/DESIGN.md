# 设计与架构基线

采用 frontend-design 及 web-reading-v1。工具工作台：保留 Excalidraw 画布为主视觉，克制顶栏、文件抽屉与清晰的同步/保存状态，不做营销首页。
Type Scale：正文16px/1.7/400；按钮与标签14px/1.55/500；提示14–16px/1.6/400；面板标题20px/1.4/600。无12px例外。中文使用系统无衬线字体。
颜色：画布#ffffff，文字#17202a，次要文字#465666，主动作#2455a4，边界#778493，危险#a12121。集中 tokens，最终计算对比度验证。
架构：前端 Excalidraw，服务端持久化与认证门禁，独立实时房间，MCP只通过当前画布接口。可持久化 scene 包含 elements、appState、files。上游接入与权限实现尚未完成，禁止公网部署。

## 一期整合预览

保留 Type Scale。顶栏使用纸灰绿底色和深绿主动作，档案置于侧栏，分享说明及撤销置于独立弹窗。桌面与窄屏保持相同字号。当前配色以 `src/workspace.css` 的语义 Token 为准。协作通过鉴权后的 WebSocket 推送，所有写入使用 HTTP 版本校验，当前白板以 generation 保护切换，归档以 revision 保护并发。

## 工作台重设计

保留上述 Type Scale，正文 16px，控件、状态及原生画布提示 14px，工作区及面板标题 20px，登录标题 28px。色彩改为石灰色外框、白色画布、墨蓝文字和钴蓝动作。状态同时显示文字，分享风险和保存错误使用正文，不依赖颜色区分。

顶栏放品牌、档案和主要操作。文档栏显示当前白板名称、保存状态和按需展开的重命名。档案桌面与画布并排，窄屏在画布内展开，关闭后焦点返回入口。≤352 CSS px 的画布使用满宽，给原生工具栏留足空间。分享使用原生模态框。登录页用与绘图任务相关的图形示意和单列移动布局。

## 工作流修订

使用本机 ui-ux-pro-max 的焦点、确认、忙碌反馈和触控规则，结合 frontend-design 与 web-reading-v1。画布继续作为主要工作区。保留正文 16px、控件和状态 14px、面板标题 20px。窄屏主要操作高度 44px。桌面档案和画布并排，中窄屏档案在画布前展开，保留两者的键盘访问。

保存副本和新建归档后显示可打开的结果。新建先说明如何处理当前画布，确认后提交。分享弹窗为当前白板创建编辑链接，提供复制及撤销。新建时归档正在共享的白板，并保持原链接可用。档案支持按显示名称搜索。取消与关闭时归还焦点，操作进行中限制重复提交。

## 全窗口画布

画布占满浏览器可用区域，使用 Excalidraw 原生绘图工具和白板菜单。新建、保存、档案、重命名和分享集中在菜单内。标题与保存状态浮在右下角，档案与操作反馈仅在需要时覆盖局部区域。展开档案时保留原画布尺寸。

桌面右下角的画板名称和保存反馈共用一行，与问号按钮对齐。保存回执在该行替代普通状态，并提供打开档案链接。标题和状态均为 14px。手机端将同一行放在原生底部工具条上方。

Excalidraw 内置菜单、素材库、输入控件、提示和弹窗通过 `src/canvas-theme.css` 映射到工作台的主题变量。浅色和深色共用组件规则，各自使用可读的颜色组合。独立渲染的帮助弹窗和悬浮提示也使用这套样式。


## Ink 全站设计（2026-11-11，当前生效）

用户指定 Hallmark Ink / paper。遵循 frontend-design 与 web-reading-v1，覆盖当前画布、档案画布、访客画布、档案浮层、分享/新建/重命名、登录与异常入口。此前各版配色记录仅作历史；颜色由 `src/tokens.css` 单点维护，基础规则位于 `src/base.css`，工作区与原生画布分别消费同一组语义变量。

- 白纸、中性黑灰、细分隔线；青绿只用于连接/启用反馈、链接和焦点。原生绘图颜色与用户画布内容保持独立。
- 主操作黑底白字；深色模式使用中性灰背景与浅色主操作，作为项目对 Ink 浅色主题的扩展。危险和错误保留语义红色，优先于原主题单一强调色限制。
- 正文16px/1.7/400；控件、状态、属性标签14px/1.55/500；面板标题20px/1.4/600；登录标题28px/1.3/600。中文系统无衬线，无12px例外，不加载外部字体。手绘画布中的用户文字不受界面字阶覆盖。
- 保留全窗口画布与原生工具入口。档案采用带搜索的单列索引；分享弹窗按说明、影响、行动分组；登录为左侧身份/原有绘图示意、右侧表单，手机重排为单列。
- 阴影只服务浮层，静态表单没有卡片阴影；无装饰动画。深色工作区显式应用文字颜色，避免只换变量却继承浅色黑字。
- 手机保持正文和控件字号，保存回执可换行；档案浮层不会挤压画布。应用自有主要按钮/输入框至少44px；原生 Excalidraw 密集绘图工具保持其现有布局。

保留所有路由、表单字段、业务处理器。移除档案行、共享副本链接、OIDC入口的装饰箭头；重连状态中分隔符从中点改为逗号。补齐原生颜色弹窗名称、主题切换按钮完整可访问名称与画布焦点。

Hallmark 静态审查中，统一控件样式（F7）是工作工具一致性的有意选择；浮层的细边界加柔和阴影（F24）用于在任意画布颜色上辨认边界，符合 Ink 浮层材质。全窗口画布按用户已确认布局保留，不应用展示站的最大容器宽度。

### 右下角状态修订
用户反馈“已载入”青绿胶囊与全局不一致。改为名称旁的14px中性次要文字，无独立底色或胶囊；同位置保存回执同步去除青绿底色，操作链接保持下划线。常驻状态不使用强调色。

## 原生白板边界修订（2026-11-11，覆盖此前原生主题与状态规定）
用户明确要求保留开源白板原生习惯：Excalidraw工具栏、属性面板、颜色、字体、快捷键、素材库内部与帮助不做视觉定制。移除canvas-theme.css导入及原生CSS覆盖；基础样式限制到应用自有区域。上游自带的10px快捷键、12px提示等按用户本次明确要求保留，不再强行套用应用的14/16px字阶。非视觉的可访问名称修复保留。

用户另要求隐藏素材库入口。0.18.1无单独关闭按钮的UIOptions开关，唯一原生CSS例外是隐藏包含default-sidebar-trigger的label整体，使其输入也退出键盘焦点顺序。只隐藏入口，不声称禁用素材库所有内部能力。

右下角不显示名称、已载入、已保存或保存回执。仅busy或正在保存时显示一个36px浅灰容器中的18px加载图标，结束后移除；减少动态效果偏好下不旋转。保存错误/重命名等需要用户处理的交互继续显示。当前文档名保留为main的可访问名称，档案内仍可查看名称。

## MCP 面板与界面语言（2026-11-12）

MCP 服务面板沿用 Ink 的纸面、浅灰选中项与中性主操作，撤销和错误保留语义红色。面板随当前内容定高，最高 40rem 且受视口限制。桌面长内容在内容区滚动，窄屏将导航和内容排进同一个滚动区域。字阶沿用 `web-reading-v1`，正文 16px、控件 14px、面板标题 20px、小节标题 18px、代码 14px。stdio 的完整接入提示通过复制操作提供，界面保留必要参数和安装说明。

应用界面支持简体中文与英文。首次使用按浏览器的语言优先顺序选择，其他语言回退到简体中文。画板菜单、登录页和 OAuth 授权页提供切换入口。显式选择保存为站点语言 Cookie，画布通过 Excalidraw 的语言参数同步切换。MCP 协议字段、代码示例中的协议标识和用户输入的白板内容仍使用各自的原文。
