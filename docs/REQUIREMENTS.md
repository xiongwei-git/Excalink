# PersonalWhiteboard 开发需求任务书

版本：一期 v0.1，2026-11-10。项目暂名 PersonalWhiteboard，非用户最终品牌名。

## 目标与已确认范围
个人自托管开源白板，优先复用 Excalidraw / yctimlin/mcp_excalidraw；Docker 部署。不是多用户 SaaS。保留原画布体验，不把首页做成文件管理页。

### 当前白板
主域名根路径 / 永远对应独立的当前白板。编辑自动持久化至服务器，下一次打开恢复。MCP 一期保留上游创建、读取、修改元素等画布相关能力，但只能操作当前白板，任何指定已保存文件的操作均拒绝。
手动保存当前白板生成独立文件及稳定 URL，不永久绑定首页。点新建时，先将非空当前内容归档为独立文件，成功后才清空当前画布；存储失败不得清空。默认名称使用时间，之后可以改名。

### 已保存白板
文件存服务器，保存记录可浏览和重新打开；名称可修改而 URL 不变。打开后手动继续编辑，保存更新同一文件，不复制成新文件。它与默认当前白板独立，MCP 不可修改。

### 分享与实时协作
认证模式下文件默认私有，仅主动分享的文件可以免登录访问；任何持有分享链接者均可编辑，无多人账号体系。第一期可撤销分享，第二期才做过期和细粒度权限。实时同步编辑同一文档，不是各自副本。旧版本或断线重连的保存必须提示冲突，不得静默覆盖。
分享当前白板时创建独立文件和 URL，所有协作者进入该文件 URL；首页保持独立。此方案用户认可为可行方向，采取此默认，不将首页永久绑定到分享文件。

### 部署认证模式
部署可选择 public（无认证）、单用户名密码、第三方个人认证。明确需求是 OIDC，可对接 Tinyauth 或类似服务；不能用仅反向代理支持冒充 OIDC 已完成。单用户认证须限制允许的身份，不能让任意 OIDC 用户成为管理者。
public 模式的已保存文件 URL 可直接编辑，无需额外授权分享步骤；分享按钮仍用于从当前白板创建独立文件与 URL。公开模式不能依靠撤销分享阻断原文件 URL 的访问，界面必须明确提示。

## 实施默认与安全边界（不是逐条用户确认）
- 协作内容自动落盘，手动保存作为明确提交；界面区分同步与已持久化。
- 空白新建不生成无意义空文件；保存/分享失败不清空当前内容。
- 文档版本递增，ETag/expected revision 并发保护；新建切换使用 generation，迟到 MCP 或离线写入不得落到新白板。
- 随机不透明文件 ID、随机能力分享令牌，日志隐藏令牌；认证模式下访问必须由服务端检查，撤销立即关闭正在协作的访客连接。
- 文件原子写入，重启恢复，路径不能由文件名控制；资源图片一并本地存储，不偷偷上传第三方分享服务。
- 密码哈希、安全会话、CSRF/Origin 校验、限流、WebSocket 鉴权。公开模式明确安全告知，默认不暴露公网。
- MCP 鉴权独立设计，不能因为匿名 public 网页就让公网任意调用管理 API。实际配置凭据与第三方持续授权另行获得批准。
- 不自动建远端仓库或发布，不修改现有服务或生产认证配置。

## 交付与验收
文档/设计/架构/部署说明、许可证与第三方声明、Dockerfile/Compose、应用实现、可重复测试。
验收场景：自动保存重开；手动保存生成固定 URL；重命名 URL 不变；新建先归档且失败不清空；双浏览器实时编辑；断线旧版本冲突；MCP 与文档隔离及新建竞态；分享撤销含已连接访客；三种认证模式；容器重启持久化；图片完整；手机与桌面、键盘、200%缩放、320px重排、可访问性和截图审查。
